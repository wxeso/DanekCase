# DanekCase Telegram Mini App

Это новая версия проекта: Telegram-бот открывает полноценный Mini App внутри Telegram. Интерфейс — тёмный игровой стиль, кейсы, инвентарь, продажа за DNC, апгрейды, ежедневный бонус и профиль.

## Что нужно
- Python 3.10+
- Telegram-бот, созданный через @BotFather
- HTTPS-домен/хостинг для Mini App (Telegram Web App не открывает обычный localhost для других пользователей)
- BOT_TOKEN, BOT_USERNAME, WEBAPP_URL, CREATOR_TELEGRAM_ID

## Настройка
1. Распакуй архив.
2. Скопируй `.env.example` в `.env`.
3. Заполни:
   - `BOT_TOKEN` — токен от BotFather (никому не показывай).
   - `BOT_USERNAME` — username бота без `@`.
   - `WEBAPP_URL` — публичный HTTPS-адрес сайта после размещения.
   - `CREATOR_TELEGRAM_ID` — твой числовой Telegram ID.
4. Установи зависимости: `py -m pip install -r requirements.txt`
5. Запусти: `py -m danekcase.app`

Приложение раздаёт сайт и API на порту 8000. На хостинге настрой проксирование HTTPS на этот порт и укажи итоговый HTTPS URL в `WEBAPP_URL`. После изменения `.env` перезапусти приложение.

## Важно
- Mini App должен быть опубликован по HTTPS, иначе кнопка Telegram Web App не заработает у пользователей.
- Сервер проверяет подпись `Telegram.WebApp.initData` на каждом API-запросе. Не доверяет Telegram ID из браузера.
- SQLite хранит игровой баланс и инвентарь. Для реального многопользовательского публичного запуска лучше перевести базу на PostgreSQL, настроить резервные копии, лимиты запросов и мониторинг.
- DanekCoin и скины — только виртуальные игровые значения: без депозитов, реальных ставок, вывода или обмена на реальные деньги.
- Визуал использует стилизованные карточки/эмодзи, не официальные изображения предметов Valve.
